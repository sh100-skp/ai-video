# Planet Live

우리 회사의 지식과 경험을 나누는 사내 강의 영상 라이브러리.
구성원은 로그인 없이 강의를 탐색하고, 관리자는 `/admin` 화면에서 코드 수정 없이 강의를 관리합니다.

## 구조

| 구분 | 내용 |
|---|---|
| 서버 | Node.js 22.5+ (외부 패키지 없음, `server.js`) |
| 데이터베이스 | SQLite 파일 1개 (`data/planet-live.db`) – 강의, 카테고리, 썸네일 이미지 모두 저장 |
| 화면 | `public/` (구성원: `index.html`, 관리자: `admin.html`) |

**권한**
- 구성원: 공개 강의 조회만 가능 (서버가 `공개` 강의만 반환)
- 관리자: 비밀번호 로그인 → 서버가 서명한 HttpOnly 쿠키 발급(8시간). 등록·수정·삭제·카테고리·비공개 강의 조회 API는 **모두 서버에서 쿠키를 검사**하며, 실패 시 401
- 비밀번호는 서버 환경변수(`ADMIN_PASSWORD`)에만 존재 (화면 코드에 없음). 5회 연속 실패 시 10분간 로그인 잠금
- 브라우저는 DB에 직접 접근할 수 없고, DB 쓰기는 관리자 검증이 걸린 서버 코드로만 가능

## 내 PC에서 실행

1. Node.js LTS 설치 (https://nodejs.org)
2. `.env.example`을 `.env`로 복사하고 `ADMIN_PASSWORD`(4자 이상, 운영 시에는 길게 권장)와 `SESSION_SECRET`(임의의 긴 문자열)을 변경
3. 실행
   ```
   npm start
   ```
4. 구성원 화면 http://localhost:3000 · 관리자 화면 http://localhost:3000/admin

테스트: `npm test`

## 배포

회사 내부 서버, 클라우드 어디든 **Node 서버 + 데이터 폴더 영구 저장**만 지켜 주세요.

- **방법 A. 사내 서버/VM**: 위 실행 방법과 동일. `pm2` 등으로 상시 실행하고, 사내 HTTPS 프록시(Nginx 등)를 앞에 둡니다.
- **방법 B. Docker**
  ```
  docker build -t planet-live .
  docker run -d -p 3000:3000 -v planet-data:/data -e ADMIN_PASSWORD=비밀번호 -e SESSION_SECRET=긴임의문자열 planet-live
  ```
- **방법 C. Render / Railway / Fly.io 등**: 이 폴더를 저장소로 올리고 Dockerfile로 배포. **영구 디스크(볼륨)를 `/data`에 연결**하고, 환경변수 `ADMIN_PASSWORD`, `SESSION_SECRET`을 등록합니다. (볼륨이 없으면 재배포 때 데이터가 사라집니다.)

주의
- 운영 환경에서는 `NODE_ENV=production`을 설정하면 로그인 쿠키가 HTTPS 전용(Secure)이 됩니다. **HTTPS가 아닌 주소에서는 로그인되지 않으니** 반드시 HTTPS로 서비스하세요. 프록시 뒤라면 `TRUST_PROXY=1`도 설정합니다.
- 백업: 서버를 잠시 멈추고 `data/` 폴더 전체를 복사해 두세요.
- 샘플 강의는 최초 실행 때 한 번만 생성되며 삭제하면 다시 생기지 않습니다.

## 관리자 사용 방법

1. `/admin` 접속 → 비밀번호 입력 (구성원 화면 오른쪽 위 “관리자” 링크로도 이동)
2. **신규 등록**: 오른쪽 위 “+ 신규 등록” → 제목, 영상 URL, 강사명, 카테고리(필수) 입력 → 썸네일 업로드, 소개(선택) → 저장. 등록일은 자동 입력됩니다.
   - 영상 URL은 `https://`로 시작하는 영상 페이지 주소입니다. 구성원이 카드를 클릭하면 이 주소가 새 창으로 열립니다.
3. **수정**: 목록의 “수정” 버튼 → 내용 변경 후 저장 (썸네일을 올리지 않으면 기존 이미지 유지)
4. **공개/비공개**: 목록의 스위치로 바로 변경. 비공개 강의는 구성원에게 보이지 않습니다. 삭제하기 전에 잠시 숨기고 싶을 때 사용하세요.
5. **삭제**: “삭제” 버튼 → 확인 창에서 확인하면 삭제됩니다. 되돌릴 수 없습니다.
6. **카테고리**: 등록 화면에서 바로 새 카테고리를 추가하거나, “카테고리 관리”에서 추가/삭제합니다. 강의가 있는 카테고리는 삭제할 수 없습니다.
7. 샘플 강의(`[샘플]` 표시)는 테스트용입니다. 실제 강의 등록 후 삭제하세요.
